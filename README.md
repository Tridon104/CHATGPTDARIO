# Dario AI Desktop

Applicazione desktop personale per Windows con login ChatGPT tramite DevKit ufficiale OpenAI, archivio chat e memoria locale.

Il progetto è ancora in fase di verifica: la compilazione e l'autenticazione reale non sono garantite. Le chat sono salvate senza cifratura; non utilizzare dati sanitari o aziendali riservati.

Il DevKit OpenAI ha una licenza non commerciale. L'eseguibile non firmato deve essere autorizzato dall'IT prima dell'uso su un PC aziendale.
